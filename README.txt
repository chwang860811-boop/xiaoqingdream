小晴 Dream World V5｜正式網站架構
================================

這一版是在 V4 基礎上補齊「真正可以營運」的前端架構，並新增 AI 互動房間。

------------
index.html        首頁
about.html        關於小晴

interaction.html  AI 互動房間：擊掌／裝可愛／撒嬌／鬼臉／吐舌頭／眨眼／愛心／揮手／晚安
journal.html      小晴日誌
shop.html         小晴櫥窗＋購物袋＋訂單表單
contact.html      聯絡小晴
thank-you.html    訂單送出後頁面

二、AI 互動到底怎麼做？
------------------------
最實用的第一階段就是你說的方式：

1. 先把小晴的「擊掌、裝可愛、撒嬌、鬼臉、吐舌頭……」各做成 2～5 秒影片。
2. 每支影片放進 assets/actions/。
3. 使用固定檔名，例如：clap.mp4、cute.mp4、cling.mp4。
4. 網頁按鈕被點擊時，JavaScript 立即切換並播放對應影片。

這樣使用者會感覺像「我按了按鈕，小晴馬上做出反應」，而不是每次重新生成 AI 影片。
這種方式速度快、成本低、角色一致性最好。

目前已預留的影片檔名：
clap.mp4 / cute.mp4 / cling.mp4 / funny.mp4 / tongue.mp4 / wink.mp4 / heart.mp4 / wave.mp4 / sleep.mp4

三、之後如何升級成真正 3D？
----------------------------
第二階段可以加入真正的 GLB/GLTF 3D 小晴模型與動畫：
Idle、Clap、Cute、Cling、Funny、Tongue、Wink、Heart、Wave、Sleep。

這時按鈕不是播放 MP4，而是呼叫同一個 3D 模型裡的 Animation Clip。
優點是可以自由改鏡頭、燈光、距離、角度；缺點是需要真正製作好 3D 模型與骨架動畫。

四、再下一階段：AI 大腦
------------------------
可以把聊天 AI 接進來：
使用者說「小晴給我一個愛心」→ AI 判斷 action=heart → 網頁播放 heart.mp4。
使用者說「我今天很累」→ AI 回覆文字＋播放安慰／抱抱動畫。

因此最後會形成：
聊天 → AI 判斷意圖 → 動作／表情 → 語音 → 畫面

注意：真正的 AI API 金鑰必須放在後端，不能寫進 HTML/JavaScript。

六、真正付款的正式版本
----------------------
目前前端已預留「銀行轉帳（人工確認）」與「綠界線上付款（正式串接後啟用）」選項。

如果要做到：
付款成功 → 自動驗證 → 訂單變成已付款 → 自動寄送數位商品下載連結
就需要正式的後端＋資料庫＋金流回呼（Webhook/ReturnURL）＋安全的數位檔案下載。

台灣可用綠界等金流。綠界的付款結果會以 Server POST 通知商家設定的 ReturnURL；商家收到後需要驗證交易結果並更新訂單。不要只靠前端畫面判斷「付款成功」。

七、你要給客人的不是 ZIP
-------------------------
ZIP 是給你自己保存／部署用的。

正式流程：
1. 你把 site 資料夾部署到網站主機。
2. 主機會給你一個網址，例如 https://你的網址.com
3. 客人只需要點這個網址。
4. 客人可以看小晴、玩 AI 互動、逛櫥窗、加入購物袋、下單。

八、本機開啟
------------
Windows：雙擊「開始預覽.bat」即可。

如果沒有 Python，也可以用 VS Code + Live Server。

九、正式上線
------------
推薦：
前端：Netlify / Vercel / Cloudflare Pages
資料庫／後端：Supabase 或 Serverless Functions
Email：正式環境可接 Resend / Postmark / SendGrid
金流：綠界等台灣金流

十、重要安全原則
----------------
不要把：
- 金流 Merchant Key
- API Key
- Email API Key
- 資料庫 Service Role Key
直接寫在前端 HTML / JS。

銀行轉帳也不建議把你的個人銀行資訊直接硬編碼進公開網站；正式商業版可使用金流提供的虛擬帳號／ATM 等方式。

十一、目前還缺你的「正式資料」
------------------------------
真正上線前，需要你最後決定：
- 正式網域名稱
- 實際商品與價格
- 哪些是數位商品／哪些需要寄送
- 金流商戶資料
- 是否啟用自動數位下載
- AI 互動影片

以上資料補齊後，就能把這個 V5 從「可展示網站」推進成「正式營運網站」。
